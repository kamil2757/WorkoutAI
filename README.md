# 🏋️ WorkoutИИ — Персональный фитнес-помощник и журнал тренировок

![Python](https://img.shields.io/badge/Python-3.10+-blue.svg)
![GUI](https://img.shields.io/badge/GUI-Tkinter-informational.svg)
![Database](https://img.shields.io/badge/Database-SQLite3-lightgrey.svg)
![AI](https://img.shields.io/badge/AI-GigaChat%20API-green.svg)

**WorkoutИИ** — это десктопное приложение для планирования и отслеживания тренировок на неделю со встроенным искусственным интеллектом на базе **GigaChat**. Программа позволяет как вручную вести дневник тренировок, так и автоматически генерировать индивидуальный план по анкете пользователя.

---

## ✨ Основные возможности

* **🤖 Умная генерация плана с ИИ (GigaChat):** заполните анкету (рост, вес, возраст, цель, опыт, инвентарь, количество и длительность тренировок, личные пожелания/ограничения) — и нейросеть составит сбалансированное расписание на неделю.
* **✍ Ручной режим планирования:** самостоятельно создавайте и редактируйте тренировки на любой день недели (ПН–ВС).
* **📋 Детальный учет упражнений:** указывайте название упражнения, количество подходов, повторений и рабочий вес.
* **☑ Отслеживание прогресса:** отмечайте статус тренировок («выполнена ☑» / «не выполнена ☐»).
* **💾 Локальная база данных:** все данные (профиль, расписание, упражнения) надежно сохраняются в локальной БД SQLite (`workoutAI.db`) и не пропадают после закрытия программы.
* **🌙 Современный темный интерфейс:** минималистичный и удобный UI, не нагружающий глаза.

## 🚀 Как запустить программу

### Вариант 1: Быстрый запуск через `.exe` (Основной способ)
Для запуска **не требуется** устанавливать Python или скачивать библиотеки — программа уже собрана в готовый исполняемый файл:

1. Откройте папку **`dist/`**.
2. Запустите файл **`WorkoutAI.exe`**.

> **Примечание для работы ИИ:** чтобы функция генерации плана через нейросеть работала, рядом с `.exe` файлом (в папке `dist`) должен лежать файл `.env` с вашим ключом авторизации GigaChat:
> `GIGACHAT_CREDENTIALS=ваш_ключ_авторизации`

---

### Вариант 2: Запуск из исходного кода (через Python)

1. Клонируйте репозиторий:
   `git clone https://github.com/kamil2757/WorkoutAI.git`
   `cd WorkoutAI`
2. Создайте и активируйте виртуальное окружение (по желанию):
   `python -m venv venv`
   `venv\Scripts\activate`
3. Установите зависимости:
   `pip install -r requirements.txt`
4. Создайте в корне проекта файл `.env` и укажите в нем ключ GigaChat:
   `GIGACHAT_CREDENTIALS=ваш_ключ_авторизации`
5. Запустите проект:
   `python main.py`

## 📦 Установленные библиотеки (`requirements.txt`)

Большинство используемых модулей (`tkinter`, `sqlite3`, `json`, `os`, `sys`, `threading`, `ctypes`) входят в стандартную библиотеку Python. Дополнительно через `pip` устанавливались следующие пакеты:

* **`gigachat`** — официальная библиотека Сбера для взаимодействия с нейросетью GigaChat API.
* **`python-dotenv`** — загрузка секретных ключей из файла окружения `.env`.
* **`pyinstaller`** — компиляция Python-скриптов в автономный исполняемый файл `.exe`.

Содержимое файла `requirements.txt`:
```txt
gigachat>=0.1.32
python-dotenv>=1.0.1
pyinstaller>=6.0.0
```

## 📁 Структура проекта

* `dist/` — **папка с готовым к запуску `.exe` файлом программы**.
* `main.py` — главный модуль графического интерфейса (экраны, логика UI, интеграция с GigaChat API).
* `database.py` — модуль работы с базой данных SQLite (таблицы `profile`, `workouts`, `exercises`).
* `workoutAI.db` — файл локальной базы данных SQLite.
* `icon.ico` / `icon.png` — иконка приложения.
* `requirements.txt` — список внешних зависимостей проекта.
* `WorkoutAI.spec` — конфигурационный файл сборки PyInstaller.
